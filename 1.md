# ohos_mqtt

## Description

This module enables applications to connect to MQTT brokers to publish messages, subscribe to topics, and receive
published messages.

## How to Install

```shell
ohpm install @ohos/mqtt
```

- The @ohos/mqtt package has enabled the SSL function and supports the sslVersion parameter.
- For details,
  see [Installing an OpenHarmony HAR](https://gitcode.com/openharmony-tpc/docs/blob/master/OpenHarmony_har_usage.en.md).

## Source Code Downloading

This project depends on the `paho.mqtt.c` and `third_party_bounds_checking_function` libraries, which are introduced
through `git submodule`. You need to specify `--recursive` when downloading the code.

  ```
  git clone --recursive https://gitcode.com/openharmony-tpc/ohos_mqtt.git
  ```

To use the `sslVersion` parameter to set the TLS version supported by the SSL/TLS context, go to the
`ohos_Mqtt\src\main\cpp\paho.mqtt.c` directory and run the `modify.sh` script to integrate the patch file in this
directory into the `paho.mqtt.c` source code.

Before building, go to ohos_Mqtt/src/main/cpp/paho.mqtt.c and run the
automatically_apply_0002-Use-certificate-content_files.sh script or use git commands to apply the
0002-Use-certificate-content.patch.

## Running the Demo

MQTT depends on the MQTT broker. Use a cloud service or set up the MQTT broker by yourself. To make sure that the demo
runs properly, change the values of the following parameters in the `emqxPage.ets` file to the corresponding values.

```typescript
    // Set Client Configuration
@State topic: string = '';
@State payload: string = '';
@State url: string = '';
@State clientId: string = '';
@State userName: string = "";
@State password: string = "";
@State isMQTTV5: boolean = true;
```

Replace `domain:port` in xts with the correct domain name and port number so that xts can run properly.

### OpenSSL Dependency

If you want to enable the SSL function for ohos_mqtt source code compilation, you need to compile OpenSSL on your own.
OpenSSL is integrated into
the [HAP](https://gitcode.com/openharmony-sig/tpc_c_cplusplus/blob/master/thirdparty/openssl/docs/hap_integrate.md) of
an application.

1. Enable the support of x86_64 for cross compilation.

2. Change the OpenSSL version number in the `HPKBUILD` file.

  ```
  pkgver=OpenSSL_1_1_1t 
  // Change the version number.
  pkgver=openssl-3.5.0
  
  patchflag=true
  //Change the patchflag
  patchflag=false

  prepare() {
    if $patchflag
  //Change the prepare
  prepare() {
    unset MAKE # Clear the MAKE environment variable
    if $patchflag
        
  build() {
    $MAKE >> $buildlog 2>&1
  //Change the build
    make -j8 >> $buildlog 2>&1
    
  package() {
    $MAKE install >> $buildlog 2>&1
  //Change the package
    make -j8 install >> $buildlog 2>&1

  check() {
    $MAKE depend >> $buildlog 2>&1
  //Change the check 
    make -j8 depend >> $buildlog 2>&1
  ```

3. Download [OpenSSL 3.5.0](https://gitee.com/mirrors/openssl/repository/archive/openssl-3.5.0.zip), run the following
   command to obtain the SHA512 value, and replace the content in the SHA512SUM file.

  ```
  sha512sum openssl-openssl-3.5.0.zip
  ```

4. Add the `thirdparty` directory to the `cpp` directory and copy the library generated after compilation to the
   `thirdparty` directory.

![img.png](./image/img.png)

5. Add the following statement to `cpp/paho.mqtt.c/CMakeList.txt`:

  ```
  #Enabling SSL
  add_definitions(-DOPENSSL)
  #Adding a Third-Party Library to a Project
  target_link_libraries(pahomqttc PRIVATE ${NATIVERENDER_ROOT_PATH}/thirdparty/openssl/${OHOS_ARCH}/lib/libssl.a)
  target_link_libraries(pahomqttc PRIVATE ${NATIVERENDER_ROOT_PATH}/thirdparty/openssl/${OHOS_ARCH}/lib/libcrypto.a)

  #Add the header file of the third-party library to the project.
  target_include_directories(pahomqttc PRIVATE ${NATIVERENDER_ROOT_PATH}/thirdparty/openssl/${OHOS_ARCH}/include)
  ```

```typescript

          // true: enable server certificate authentication, false: disable,default is true.
```

```typescript
          // The file in PEM format containing the public digital certificates trusted by the client.
          // It must set local file path in your device and the file must can be accessed.

          // If both trustStore (file path) and trustStoreContent (file content) are provided,
          // trustStore takes precedence.

          // The file in PEM format containing the public certificate chain of the client.
          // It may also include the client's private key.
          // It must set local file path in your device and the file must can be accessed.
          // If both keyStore (file path) and keyStoreContent (file content) are provided, keyStore takes precedence.

          // If not included in the sslKeyStore, this setting points to
          // the file in PEM format containing the client's private key.
          // It must set local file path in your device and the file must can be accessed.
          // If both privateKey (file path) and privateKeyContent (file content) are provided,
          // privateKey takes precedence.
          privateKey: fileDir + "/client.key",
          // The file in PEM format containing the public digital certificates trusted by the client.
          // Provided as a string or Uint8Array containing the PEM format data.
          // If both trustStore (file path) and trustStoreContent (file content) are provided,
          // trustStore takes precedence.
          trustStoreContent: "trust store content",
          // The file in PEM format containing the public certificate chain of the client.
          // It may also include the client's private key.
          // Provided as a string or Uint8Array containing the PEM format data.
          // If both keyStore (file path) and keyStoreContent (file content) are provided, keyStore takes precedence.
          keyStoreContent: "key store content",
          // If not included in the sslKeyStore, this setting points to
          // the file in PEM format containing the client's private key.
          // Provided as a string or Uint8Array containing the PEM format data.
          // If both privateKey (file path) and privateKeyContent (file content) are provided,
          // privateKey takes precedence.
          privateKeyContent: "private key content",
        }
```

### willOptions

| Name      | Type    | Mandatory | Default Value | Description                    |

| qos       | QoS     | No        | 0             | QoS of LWT messages.           |
